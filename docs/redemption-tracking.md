# Redemption cards and participation

Existing OBS horizontal and vertical compact/regular browser sources keep their dimensions. All five cards use the firefly celebration frame, clear platform badges, and a brief entrance animation. Live Viewer Spotlight requests populate the collectible card with the creator-permitted fields.

## Commands and confirmations

Twitch and Kick keep their native rewards. Facebook, TikTok and YouTube can spend Viewer Foundation points using the saved First Five, Fan Crown, Roll Call and Spotlight commands. Replies go to the source platform. Check the Commands page for current names.

The installed help timers start two minutes after their own platform is live, repeat every 20 minutes, and skip missed occurrences. Each timer rotates two short messages with the configured command names and costs. Update those timers in Timed Actions if you later rename commands or change costs. Fan Crown is described as a rising price.

## Village Lurk Tracker

The optional add-on is enabled in this installation. Use !lurk (or the matching Viewer Foundation lurk command). Ordinary chat or another recognized command ends the lurk automatically. Repeating !lurk does not restart its clock or add visits. Stream offline and Bridge shutdown end active lurks. Restarts exclude downtime. Bots, ignored accounts and simulations are excluded. Returning viewers are cleared quietly by default.

## Monthly recaps

First Five, Fan Crown, Village Roll Call, Chat Play and lurk rankings/activity totals renew each month, alongside Community Analytics' monthly participation season. The calendar uses America/Chicago; running checks detect a new month within one minute, and a closed Bridge catches up on its next start. Native Fan Crown administration still requires its existing approved Controller to confirm the reset.

The host saves a bounded recap before replacing monthly scores. The overview banner links to Community Analytics → Monthly Village Recaps, with leaders, totals and downloadable JSON. Recaps are local; no Discord destination has been configured. The view shows the most recent 12 archived months.

Points balances, levels, account links, lifetime totals, current stream placements and games in progress remain intact. An ongoing lurk is split at the calendar boundary without creating another visit. Recaps contain participation summaries rather than chat text, tokens or provider user IDs.
