**THSV StreamBridge** is a free, open-source companion for Streamer.bot that turns Twitch, YouTube, Kick, TikTok (via TikFinity) and a Facebook Page into one stream. It runs on your PC; nothing is hosted and it never asks for platform passwords.

**What you get**
• One chat overlay and alerts for every platform, with emotes (Twitch, BTTV, 7TV, Kick)
• Commands, timed messages and channel-point rewards that work everywhere, plus points with !buy
• Going live/ending, break timers, Starting Soon countdown, raid finder, clip player
• Community extras: polls, giveaways, quotes, Magic 8-Ball, Streamer Punishments and more
• Live captions and chat translation
• A Setup Wizard in your browser that walks you through all of it

**Needs:** Windows 10/11 64-bit and Streamer.bot **1.0.7 or newer** (stable works). OBS, Meld or Streamlabs for overlays.

**Setup (about 30 minutes)**
1. In Streamer.bot, turn on **Servers/Clients > WebSocket Server** (127.0.0.1, port 8080, Auto Start).
2. Download the latest ZIP from the GitHub releases, right-click > Properties > Unblock, extract, run **Install THSV StreamBridge.cmd**.
3. The Setup Wizard opens. In **Start here**, tick where you stream and pick **Essentials**.
4. On **Streamer.bot**, create the one import and import the `.sb` file. Close and reopen Streamer.bot once.
5. Open **Setup checklist** and approve the actions it lists.
6. Add the chat and alert browser sources it shows, then fire a test alert.
