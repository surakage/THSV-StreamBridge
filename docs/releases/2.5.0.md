# THSV StreamBridge 2.5.0

Version `2.5.0` is the synchronized stable baseline for the bridge, all 29 first-party add-ons, and all 36 Streamer.bot imports.

## Highlights

- Five practical add-ons graduate into the public package set: Creator Utility Pack, Chat Play Pack, Free Game Check, Accessibility Captions, and the shared Clip Library Cache.
- Chat Guard gains optional, double-approved enforcement while remaining observe-only by default.
- Viewer Foundation and Viewer Spotlight gain migration, achievements, carousel/credits presentation, Stream Score, reward requests, Discord snapshots, and privacy-deletion propagation.
- High-frequency internal lookup workers no longer flood Streamer.bot Action History. User-visible delivery, moderation, reward, scene, and control actions remain auditable.
- Every add-on now includes its own `SETUP.md`, appears in the setup-guide index, and exposes the same setup/health/repair guidance directly in the wizard.
- The wizard acceptance ledger distinguishes automated checks, offline/manual acceptance, and genuine provider acceptance.

## Install

1. Download `THSV-StreamBridge-2.5.0.zip` and `THSV-StreamBridge-2.5.0.zip.sha256` from this release.
2. Verify the checksum and GitHub artifact attestation using `RELEASE-VERIFICATION.md`.
3. Extract the archive and run `Install THSV StreamBridge.cmd`. Normal updates preserve creator configuration, secrets, installed add-ons, state, logs, uploads, and backups.
4. Open the local setup wizard and follow the Streamer.bot inspection and core-package steps.

For an optional feature, download only its matching `THSV-StreamBridge-AddOn-<Name>-2.5.0.zip`. Its `.thsv-addon`, matching `.sb` import when required, checksum, `INSTALL.txt`, and detailed `SETUP.md` are kept together.

## Compatibility and safety

- Windows x64 remains the supported portable target.
- Streamer.bot `1.0.5-beta.2` is now recommended as a post-release compatibility update. Beta.1 remains the last recorded THSV live-smoke baseline until beta.2 completes the focused re-acceptance checklist. Individual package manifests retain the oldest verified compatible floor when they do not need a newer API.
- Add-ons remain disabled until the creator reviews permissions, action grants, settings, and restart requirements.
- Simulated results do not count as provider acceptance. High-impact provider events without verified stable identity remain blocked.
- This is unsigned portable software. SHA-256 checksums, GitHub Actions build provenance, and the SBOM provide the free publisher/integrity verification path.

## Validation target

The release pipeline reruns build, lint, typecheck, configuration validation, the full unit/integration suite, browser acceptance, deterministic Streamer.bot generation, 29 add-on packages, portable Windows packaging, checksums, SBOM generation, and GitHub artifact attestations before publication.
