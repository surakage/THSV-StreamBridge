# THSV StreamBridge 4.0.0

Version 4 makes the full Bridge experience easier to install, update, and recover without turning every built-in feature into a separate download.

## What changed

- Seven built-in extension groups now install and operate as part of the main StreamBridge package: Broadcast Director, Clip Engine, Community Rewards, Community Messaging, Community Insights, Community Play, and Voice & Language.
- Viewer Foundation, Community Analytics, and Ko-fi Donations are built-in integrations with dedicated wizard pages.
- The wizard generates one selectable Streamer.bot import containing the required framework plus only the extensions and optional add-ons the creator chooses.
- The public release now publishes separate downloads only for 11 genuinely optional add-ons. Bundled extension components are no longer duplicated as misleading add-on ZIPs.
- The installer removes inactive application-only folders after the new version passes its health check while preserving configuration, secrets, logs, backups, creator data, and add-on state.
- Setup guidance, extension and add-on navigation, responsive layouts, overlay previews, action feedback, update discovery, the tray shell, and one-click startup have been consolidated for a fresh-computer installation.
- All 41 Streamer.bot packages are regenerated from reviewed source at 4.0.0 and indexed with size and SHA-256 integrity metadata.

## Downloads

Most creators need only `THSV-StreamBridge-4.0.0.zip` and its adjacent checksum. Optional add-on ZIPs are needed only for features shown on the wizard's **Add-ons** page. Built-in features shown on **Extensions**, **Viewer Foundation**, **Community Analytics**, or **Ko-fi Donations** are already present in the main archive.

## Upgrade notes

Run the 4.0 installer over the existing installation. It preserves creator-owned data and removes inactive application versions after the new version is healthy. After the wizard opens:

1. Review the seven extension groups and enable the groups you want.
2. Review Viewer Foundation and Community Analytics settings.
3. Generate one new 4.0 Streamer.bot import for the selected features and import it with overwrite enabled for matching THSV actions.
4. Use the generated trigger checklist to verify creator-owned triggers; the installer does not silently rewrite them.
5. Restart StreamBridge when requested, then run readiness, overlay preview, and harmless action checks before going live.

Historical release assets remain historical evidence. For a new installation, use only the latest 4.0 core archive and current optional add-ons.
