# THSV StreamBridge 4.0.4

Version 4.0.4 turns the first full live-session findings into a more seamless broadcast lifecycle, from automatic scene discovery through reliable go-live recovery and clean shutdown.

## Live lifecycle reliability

- OBS broadcast state is monitored continuously, allowing StreamBridge to recover a session that was already live at startup and close recovered Twitch, YouTube, Kick, and TikTok state when OBS stops.
- Repeated online or offline provider states are idempotent, and browser overlays reset only once after the final offline transition.
- Live Beacon and direct OBS recovery share the same timer and overlay session state without fabricating platform events.
- Simulated timed-action tests no longer leave pending shuffle selections, and stopping a session clears legacy pending choices.

## Scene and trigger setup

- The wizard can discover OBS scenes directly and request scene catalogues from OBS, Meld, and Streamlabs through the reviewed Streamer.bot scene-catalog package.
- Scene-dependent features use selectable provider scenes instead of requiring exact names to be copied manually.
- Trigger Assurance audits the installed Twitch, YouTube, and Kick intake actions, explains Streamer.bot 1.0.7 compatibility exceptions, and detects missing, disabled, or duplicate triggers.
- Native scene relays normalize provider scenes consistently and preserve creator-owned wizard settings.

## Countdown, clips, and raids

- Starting Soon Countdown can recover from a mid-live Bridge start and uses current scene evidence to avoid missed launches.
- Random Clip Player coordinates more safely with active scenes and retained clip-library state.
- Raid Scout falls back to Twitch's bounded clip embed or another selected clip when Streamer.bot receives no playable direct download URL.
- Ending ads, raid dispatch, presentation queues, and broadcast-stop confirmation remain isolated so a clip failure cannot block the raid.

## Verification

- All 42 Streamer.bot imports are regenerated at 4.0.4.
- Unit, integration, browser, wizard, packaging, startup-chaos, and protected release checks cover the revised lifecycle.

## Install

Run `Install THSV StreamBridge.cmd` from the extracted release. The installer preserves creator configuration, wizard settings, secrets, logs, add-on state, and recovery access while replacing only release-owned application files.
