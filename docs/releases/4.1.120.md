# THSV StreamBridge 4.1.120

## Changed

- Picking your streaming app now also changes which app "Start all streaming tools" opens: the picked app starts and the other streaming apps no longer do. Nothing changes if no streaming app was set to start.

## Fixed

- On the readiness check, "On-stream overlays" now reads the overlays straight from your streaming app when it can (SprigCast and OBS), and lists any that are missing. Before, it could show an old count on SprigCast.
- The overlay link check (wrong port, feature turned off or not installed) now checks SprigCast's own sources too, not only OBS's scene collection.

## How to update

Open the Wizard, press Check for updates and then Update now. Your settings and extensions are kept, and it never installs while you are live.
