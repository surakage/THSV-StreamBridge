# THSV StreamBridge 4.1.160

## New

- **Connect OBS for me** under Scene connections. StreamBridge reads OBS's own WebSocket port and password from this PC, so you don't copy them. If OBS's WebSocket server is switched off, it says where to switch it on.
- **Let Meld show overlays** on the Overlays page. Meld Studio shows browser overlays blank until Windows lets it open pages on this PC; the button asks Windows for that (one Yes on the Windows prompt), then restart Meld.
- **Add all** and **Make starter scenes** now work with Streamlabs Desktop too, through its Remote Control token.
- Extensions that need a platform you have not turned on (for example Raid Scout and Random Clip Player need Twitch) show "Needs Twitch" and are hidden from the suggested list, with a count of how many.

## Changed

- Wording viewers and Discord see no longer assumes a village. Live Beacon says "See you in chat! 🌿", Local Clock says "It is {time} on {date} here.", the Magic 8-Ball answers with "The stars say yes" and similar, Roll Call and Fun Commands use plain words, and Discord webhook names and footers drop "THSV". Settings you already saved keep your own wording; only empty settings use the new defaults.
- Extensions with Village names now have plain names: Lurk Tracker, Hydration Station, Fun Commands, Giveaway Draw, Jukebox, Chat Polls, Roll Call and Voice Relay. Their ids, commands and Streamer.bot actions stay the same.
- The TikTok switch says "Go LIVE and End LIVE together with your streaming app" instead of OBS.

## Fixed

- A wrong OBS password said "OBS WebSocket closed before the scene query completed". It now says OBS turned down the password and how to fix it. The messages no longer mention an environment variable.
- The guides pointed to buttons and sections that no longer exist ("Run pre-stream check", "Browser-source checklist") and never said to connect your streaming app. Quick start now has a step for it, and a test checks that every page and section a guide names exists in the Wizard.

## How to update

Open the Wizard, press Check for updates and then Update now. Your settings and extensions are kept, and it never installs while you are live.
