# THSV StreamBridge 4.1.124

## Changed

- SprigCast's Blackout no longer falls back to a Color Correction filter when the Hide it plugin is missing, because a filter only changes one canvas. The check and the effect ask you to add Hide it under Tools › Plugin store instead.

## Fixed

- In SprigCast, Blackout, Pixelate and Barrel roll now show on the horizontal and the vertical canvas together. A source is changed everywhere it shows. A sprig is changed in the bloom on air (Barrel roll spins it everywhere).
- Blackout and Pixelate now work on a sprig in SprigCast, not only on a source.

## How to update

Open the Wizard, press Check for updates and then Update now. Your settings and extensions are kept, and it never installs while you are live.
