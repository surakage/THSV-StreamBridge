# THSV StreamBridge 4.0.11

## Corrected release validation

- Carries forward the unreleased 4.0.10 live captions, stream-break guard, and Voice Relay hardening changes.
- Fixes the protected Windows release check to verify every trigger in the shipped registry, including the five optional scene and ad triggers, instead of assuming only 29 platform triggers.
- Verifies that all 34 registered triggers can be detected, restored without changing action bodies, survive a restart boundary, and be rolled back from a verified backup.
- Aligns the bridge, add-ons, and generated Streamer.bot imports to 4.0.11.

## Install or update

Run `Install THSV StreamBridge.cmd` from the extracted release. The installer preserves creator configuration, credentials, add-on state, action grants, executable selections, and existing Streamer.bot data while replacing release-owned application files.

After installation, review **Live Captions** in the Wizard, test the selected microphone in Streamer.bot Voice Control, add the `/overlay/captions` browser source, and use the preview before enabling captions for a stream.
