# THSV StreamBridge 4.1.94

## Changed

- Every extension is lighter during a stream. StreamBridge now remembers each extension's saved data instead of opening and re-checking its file on every chat message, and it skips saves that change nothing. Reading that data is about four times faster and an unchanged save about twice as fast.
- Chat emote lists refresh once an hour instead of every half hour.
- The log writes about half as many lines for each event and extension action.
- Countdown and subathon timer overlays only redraw when the shown second changes.

## How to update

Open the Wizard, press Check for updates and then Update now. Your settings and extensions are kept, and it never installs while you are live.
