# THSV StreamBridge 2.5.1

This patch release makes the setup wizard easier to follow and refreshes the complete bridge, add-on, and Streamer.bot package set on one synchronized version.

## Highlights

- Every add-on card starts with a short summary of settings, Streamer.bot connection, required approvals, and setup length.
- Only the essential settings section opens by default. Detailed install, repair, maintenance, acceptance, and custom-action tools stay available without crowding the page.
- The wizard lists the exact recommended Streamer.bot actions for each broker-enabled add-on and can select their stable IDs after a live inspection.
- Clip Courier now uses `!clip` to create a new Twitch clip and delivers only current-stream clips. Its Discord delivery helper remains triggerless.
- Chat Guard includes the disabled-by-default `!guardtrust` reply command and guided trusted-viewer management.
- All 29 add-ons and all generated Streamer.bot imports are aligned to `2.5.1`.

## Install or update

1. Download `THSV-StreamBridge-2.5.1.zip` and `THSV-StreamBridge-2.5.1.zip.sha256` from this release.
2. Verify the checksum using `RELEASE-VERIFICATION.md`.
3. Extract the archive and run `Install THSV StreamBridge.cmd`.
4. Open the local wizard, inspect Streamer.bot, and use each add-on's recommended-action button before saving grants.
5. Import an add-on's matching `2.5.1` `.sb` only when its setup page says an import is required. Back up Streamer.bot before replacing existing custom code or trigger bindings.

Existing creator configuration, secrets, add-on state, uploads, logs, and backups remain outside the versioned application directory and are preserved by the installer.

## Acceptance boundary

Automated, offline/manual, and genuine-provider acceptance remain separate. Financial, moderation, reward, raid, Discord, translation, voice, and other side-effecting paths still require the provider evidence recorded in the wizard acceptance ledger.
