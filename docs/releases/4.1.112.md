# THSV StreamBridge 4.1.112

## Changed

- For SprigCast the form hides the password box and asks only for the pairing code, since StreamBridge never needs SprigCast's password. A password typed earlier is ignored when pairing.

## Fixed

- The Scene connections form now follows the app you pick. The name example, the password hint and the address change with the app, and switching app clears a password you typed for the last one.
- A SprigCast connection is saved with the address SprigCast really uses (for example ws://127.0.0.1:4456/sprigcast when OBS is open), so the saved list shows the right port. After saving, the form stays on the same app.
- The pairing code can be typed the way SprigCast shows it, with a space (262 275).

## Also in this update

- New text is translated into the nine Wizard languages.

## How to update

Open the Wizard, press Check for updates and then Update now. Your settings and extensions are kept, and it never installs while you are live.
