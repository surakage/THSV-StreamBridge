# THSV StreamBridge 4.1.164

## New

- An overlay can be shown in a small browser source that only covers the part it draws. Add `sbCanvas=1920x1080&sbAt=X,Y` to the overlay's URL and size the source to the part you crop: the page lays out exactly as it does full-screen (text sizes, card spots and screen-size rules all follow 1920x1080) and shows the area whose top-left corner is X,Y. Nothing changes on stream, and a small page costs the streaming app much less memory and graphics work than a full-screen one. Works for alerts, captions, the Emote Wall page and every add-on overlay; a vertical canvas uses `sbCanvas=1080x1920`.

## How to update

Open the Wizard, press Check for updates and then Update now. Your settings and extensions are kept, and it never installs while you are live.
