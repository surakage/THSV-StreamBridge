# THSV StreamBridge 4.0.1

Version 4.0.1 makes the Version 4 installation policy explicit: one active application version, with no persistent rollback copy.

## Changed

- A successful install or upgrade removes every inactive directory beneath the managed `app` folder.
- Successful installation records no longer retain a `previousVersion` pointer.
- Creator configuration, secrets, logs, backups, uploads, extension state, and optional add-on state remain preserved.
- Installation still uses private staging and temporary transactional recovery. If activation fails before the new version is healthy, the working installation is restored; after success, that temporary recovery data is deleted.

## Install

Run `Install THSV StreamBridge.cmd` from the extracted release. The installer verifies the release, preserves creator-owned data, activates 4.0.1, checks local health, and removes inactive application versions.

After the wizard opens, use **Streamer.bot -> One Streamer.bot import** to select the features you use and generate one combined import plus its recommended-trigger checklist.
