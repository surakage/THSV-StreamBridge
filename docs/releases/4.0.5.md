# THSV StreamBridge 4.0.5

Version 4.0.5 adds a privacy-safe operational confidence layer and makes core upgrades carry every already-installed bundled extension forward automatically.

## Live Confidence Center

- The wizard brings configuration drift, readiness rehearsal, module health, recovery evidence, and the latest post-stream report into one operational view.
- A redacted 30-minute timeline and dry replay help identify lifecycle gaps without retaining chat text, viewer identities, tokens, or creator secrets.
- OBS interruptions and recovered sessions are recorded as explicit evidence, making scene and broadcast-state instability easier to diagnose after a stream.
- Repair and replay controls remain creator-confirmed; routine diagnostics are local and read-only.

## Seamless extension migration

- A Bridge upgrade now synchronizes every already-installed, core-managed extension from the verified bundled packages before module startup.
- Enabled choices, approved action grants, private settings, and extension state are preserved.
- Creator-removed bundled components stay removed, and optional add-ons are not installed or re-enabled implicitly.
- Package compatibility and checksums are still verified before an updated extension can load.

## Verification

- All 42 Streamer.bot imports are regenerated at 4.0.5.
- Unit, integration, browser, wizard, packaging, startup-chaos, migration, and protected release checks cover the revised operational flow.
- Genuine provider, broadcast-app, moderation, financial, reward, raid, voice, and outbound-chat acceptance remains separate from automated validation.

## Install or update

Run `Install THSV StreamBridge.cmd` from the extracted release. The installer preserves creator configuration, wizard settings, secrets, logs, extension settings and state, optional add-ons, and recovery access while replacing release-owned application files.
