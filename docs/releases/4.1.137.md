# THSV StreamBridge 4.1.137

## Changed

- The Punishments tracker heading has real spaces between "PUNISHMENTS", "OWED" and the month, so tools that read the page's text no longer see "PUNISHMENTSOWED". The panel looks the same.

## Fixed

- With OBS open next to SprigCast, StreamBridge thought SprigCast was closed and paused its SprigCast link. Both apps can listen on port 4455 at once (OBS on every address, SprigCast on 127.0.0.1), and StreamBridge only looked at the first listener it found. It now checks every program listening on the port and picks the one you saved, for SprigCast, OBS, Meld, Streamlabs and Streamer.bot.
- Raid Scout's Set it up for me failed with "SprigCast: the action failed" when it had to add the "StreamBridge Raid Clip Sound" row. SprigCast refuses muting a sound made earlier in the same change, so the row is created muted and the mute is sent again right after the change is applied.

## How to update

Open the Wizard, press Check for updates and then Update now. Your settings and extensions are kept, and it never installs while you are live.
