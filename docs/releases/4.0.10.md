# THSV StreamBridge 4.0.10

## Live captions and Streamer.bot alpha.6 compatibility

- Adds built-in private live captions from Streamer.bot Voice Control dictation with a dedicated transparent browser-source overlay.
- Adds full caption styling for font, size, weight, color, outline, shadow, background, alignment, position, width, line count, and animation.
- Raises the new-install confidence floor to `0.70` and rejects low-confidence recognition before it reaches the overlay.
- Uses close Streamer.bot alternative transcriptions when a creator-authored accent correction recognizes a better phrase.
- Adds a bounded local `heard => intended` correction dictionary for recurring accent, name, and community-term mistakes without retaining microphone audio or transcript history.
- Adds default-on profanity masking plus creator-defined words and phrases, using complete word boundaries to avoid censoring innocent substrings.
- Reports published, corrected, alternate-selection, masked, stale, repeated, and failed caption counters without logging caption text.
- Prevents delayed WebSocket events, browser reconnection, background timer throttling, and stream transitions from reviving stale captions.
- Keeps caption preview validation safe and shows clear Wizard errors for malformed or duplicate correction/filter entries.
- Adds exact Streamer.bot `1.1.0-alpha.6` trigger-schema compatibility from the creator host's sanitized pre/post-upgrade evidence while keeping future alpha builds inspection-only.
- Regenerates all versioned Streamer.bot imports and first-party package metadata for 4.0.10.

## Install or update

Run `Install THSV StreamBridge.cmd` from the extracted release. The installer preserves creator configuration, credentials, add-on state, action grants, executable selections, and existing Streamer.bot data while replacing release-owned application files.

After installation, open **Live Captions** in the Wizard, test the selected microphone in Streamer.bot Voice Control, add the `/overlay/captions` browser source, and use the preview before enabling captions for a stream.
