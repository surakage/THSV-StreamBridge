# THSV StreamBridge 4.0.6

Version 4.0.6 completes the production-readiness pass with safer application startup, native broadcast-app scene connections, and approval-gated recovery that preserves the creator's working configuration.

## Seamless startup and broadcast apps

- Exact executable selections are retained for Streamer.bot, Speaker.bot, OBS, Meld, Streamlabs, and the preferred browser.
- Missing, moved, or incorrect paths produce bounded recovery guidance instead of locking up the launcher or stopping healthy sessions.
- Native OBS, Meld, and Streamlabs WebSocket profiles protect credentials locally, bind scene data to the selected process, and expose conflicts, maintenance windows, latency, reconnects, and acceptance history in the wizard.

## Operational confidence and recovery

- Scheduled preflight, configuration drift checks, trigger assurance, reliability scoring, and post-stream reports identify unstable paths before the next broadcast.
- Repairs, baseline replacement, trigger reconciliation, and restore operations require explicit creator approval and create rollback evidence first.
- Support bundles retain a sanitized operational timeline without chat text, viewer identity, tokens, or passwords.

## Preserved creator setup

- Upgrades retain wizard settings, selected executable paths, encrypted credentials, extension state, action grants, and enabled add-on choices.
- Recovery restores all previously enabled verified bundled extensions instead of relying on a fixed component list.
- All 42 Streamer.bot import packages are regenerated for 4.0.6 with their existing stable action identities and trigger guidance.

## Verification

- Lint, type checking, unit and integration tests, Windows installer and lifecycle acceptance, startup-chaos tests, and the complete 61-case browser suite gate the protected release.
- Genuine provider events and creator-visible overlay behavior remain live acceptance items; automated tests do not fabricate evidence of real platform delivery.

## Install or update

Run `Install THSV StreamBridge.cmd` from the extracted release. The installer preserves creator configuration and state while replacing only release-owned application files.
