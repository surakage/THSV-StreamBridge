# THSV StreamBridge 4.1.146

## Changed

- SprigCast now sends its events in groups while you're live (about 10 a second), so a quick run of scene or stream changes can arrive together. StreamBridge reads every event in a group in order, whether SprigCast sends them as separate messages, as one list, or wrapped as `events` or `batch`, and still answers its own requests in between. A group with several scene changes makes StreamBridge read the scene once (the last one wins), and a group with stream and recording changes makes it check the stream state once instead of once per event.

## How to update

Open the Wizard, press Check for updates and then Update now. Your settings and extensions are kept, and it never installs while you are live.
