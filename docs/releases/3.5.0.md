# THSV StreamBridge 3.5.0

Version 3.5 is the final synchronized setup pass before the creator begins regular streaming. It packages the bridge, wizard, overlays, 34 first-party add-ons, and 38 generated Streamer.bot imports on one visible version.

## Included

- Guided wizard improvements across core and add-on setup, including persistent disclosure state and clearer trigger/action ownership.
- Village Polls as the universal cross-platform polling add-on, replacing the retired Creator Utility Pack duplicate counter.
- Chat Play Pack commands, fallback trivia/unscramble content, and optional bounded provider-backed question and word retrieval.
- Viewer Lobby, Village Draw, Chat Guard, community features, clip tools, command directory, overlay reliability, and package-integrity corrections completed after 3.0.0.
- Separate add-on ZIPs containing only the matching `.thsv-addon`, setup guide, checksum, and add-on-specific Streamer.bot import when required.

## Installation

Download `THSV-StreamBridge-3.5.0.zip` and its adjacent SHA-256 file from the official GitHub release. Verify the checksum and GitHub artifact attestation, extract the ZIP, and run `Install THSV StreamBridge.cmd`. Existing configuration, secrets, approved action grants, uploads, logs, and add-on private state are preserved.

Add-ons remain explicit creator choices. Install the matching 3.5.0 add-on bundle through the authenticated wizard and import only its bundled Streamer.bot package. Twitch and Kick Reward Redemption triggers belong on their existing native platform intake actions; downstream processors and add-on controllers remain triggerless unless their setup guide explicitly says otherwise.

## Acceptance boundary

Automated tests, browser tests, package verification, local installation, and Streamer.bot connectivity prove framework cohesion. They do not prove a genuine provider event or external side effect. Use the add-on acceptance ledger and first-live checklist before enabling financial, reward, moderation, raid, Discord, TTS, scene-changing, or outbound-chat behavior.
