# THSV StreamBridge 4.1.126

## Fixed

- A Preview button on a timer or panel extension (for example the Stream Launch Countdown, Reward Timers or the Streamer Punishments tracker) replaced the real timer that a reloaded page gets back, so a refresh could show the sample again. Previews no longer replace it.

## Also in this update

- New: an overlay test sequence for checking a layout without an audience. It fires a list of test events (alerts, a chat sample, a caption, Emote Wall effects and extension previews) on the overlay pages a fixed gap apart, and records when each one was sent. It only draws on the overlay pages and refuses to run while you are live. See "Overlay test sequence" in the browser overlay guide.

## How to update

Open the Wizard, press Check for updates and then Update now. Your settings and extensions are kept, and it never installs while you are live.
