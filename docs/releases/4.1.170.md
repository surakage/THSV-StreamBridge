# THSV StreamBridge 4.1.170

## Changed

- StreamBridge speaks SprigCast's new API 1 when SprigCast offers it (fields under `data`, events as `{event, group, data, at}`, camelCase answers). With an older SprigCast it stays on API 0 as before. Nothing changes on stream.

## How to update

Open the Wizard, press Check for updates and then Update now. Your settings and extensions are kept, and it never installs while you are live.
