# THSV StreamBridge 4.1.106

## New

- SprigCast support. Add SprigCast under Setup Wizard > Scene connections (Find apps finds it on port 4455 or 4456). StreamBridge talks to SprigCast through SprigCast's own API (the address ending in /sprigcast), never its OBS-compatible door, and it reads your blooms as scenes, so scene lists, scene-based automations, live and recording state, screenshots (Snap, Discord screenshots) and Save power all work with SprigCast. Turn the API on in SprigCast under Settings > Connections and copy its password into the connection.
- SprigCast in the programs that open with one button. Pick pythonw.exe in SprigCast's python folder; StreamBridge starts SprigCast with it and only counts that Python as SprigCast.

## Changed

- Add overlays explains how to add them by hand in SprigCast (+ > Web page), since SprigCast can't create sources for other apps yet.

## How to update

Open the Wizard, press Check for updates and then Update now. Your settings and extensions are kept, and it never installs while you are live.
