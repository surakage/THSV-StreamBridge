# THSV StreamBridge 4.1.111

## New

- Pair StreamBridge with SprigCast instead of typing its password. Under Scene connections, pick SprigCast and type the 6-digit code from SprigCast's Settings › Connections › Pair a device. StreamBridge saves the pairing key protected on this PC and never asks for SprigCast's password. If SprigCast forgets the pairing, the message says how to pair again.
- StreamBridge finds SprigCast's port by itself from SprigCast's connection file, so it keeps working when SprigCast moves to 4456 because OBS is open. A file left behind after a crash is ignored.
- Streamer Punishments blackout works in SprigCast without the Hide it plugin. Set it up for me adds a black Color Correction filter to the source, and the effect turns it on for its seconds, then off again.
- Overlays show "Seen in SprigCast" on the Overlays page, like they do in OBS.

## Changed

- Add all and starter blooms use the canvas sizes SprigCast reports and stretch full-screen overlays to fill each canvas (needs SprigCast 0.2.0; older SprigCast keeps working as before).

## Also in this update

- New text is translated into the nine Wizard languages.

## How to update

Open the Wizard, press Check for updates and then Update now. Your settings and extensions are kept, and it never installs while you are live.
