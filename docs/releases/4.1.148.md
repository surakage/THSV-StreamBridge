# THSV StreamBridge 4.1.148

## Fixed

- The combined **Redemption cards** and **Sounds** pages (new in 4.1.146) showed a solid dark box instead of a see-through page, so no card could be seen. The browser paints a frame solid when its colour scheme differs from the page around it; the combined page now uses the same scheme as the cards.
- Custom CSS you set on a combined page in OBS or SprigCast now reaches the cards inside it. Before, it only styled the empty outer page, so cards lost a custom look (like the Village Post frames). Each card gets a copy of that CSS, kept up to date when you change it. Use the custom CSS of one of your current card sources (for example Fan Crown) on the combined page.

## How to update

Open the Wizard, press Check for updates and then Update now. Your settings and extensions are kept, and it never installs while you are live.
