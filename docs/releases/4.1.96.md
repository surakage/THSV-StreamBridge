# THSV StreamBridge 4.1.96

## Fixed

- Test & finish no longer warns that an overlay has no browser source when OBS has only shut that source down while its scene is hidden. An overlay that connected in the last 30 days counts as set up.

## How to update

Open the Wizard, press Check for updates and then Update now. Your settings and extensions are kept, and it never installs while you are live.
