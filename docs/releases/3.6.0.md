# THSV StreamBridge 3.6.0

Version 3.6.0 turns the most-used creator tools into a more cohesive StreamBridge experience while keeping optional add-ons independently installable and recoverable.

## Highlights

- Built-in extensions now include Community Analytics, Custom Counter, Follower Pulse, Village Voice, Translate, Chat Play Pack, and Village Fun Commands.
- The wizard separates Extensions and Add-ons, uses more of the available display safely, provides clearer feedback, and offers live overlay editing previews.
- A native Windows tray shell and ordered one-click launcher make local startup, token access, installation discovery, and stale-session recovery easier.
- The updater can discover signed releases automatically, stage them safely, and refuses disruptive application while a platform is live.
- Streamer.bot imports are regenerated from reviewed source and published with a canonical index and integrity metadata.
- Raid Scout and streaming-output shutdown have stronger fallbacks, while Aitum failure no longer prevents the main broadcast from ending.
- Random Clip Player and shared browser media handling have improved playback continuity and stale-state recovery.
- Chat Guard, Quote Vault, Hydration Station, Starting Soon Countdown, Follower Pulse, overlays, alerts, and shared presentation queues received reliability and usability hardening.

## Release assets

The main Windows package contains StreamBridge, its wizard, tray launcher, runtime, documentation, and built-in Streamer.bot imports. Optional add-ons are published as separate bundles with their matching Streamer.bot imports where required. Every release archive includes a SHA-256 checksum; the release workflow also publishes an SBOM and GitHub build-provenance attestations.

Existing creator-owned settings and state remain preserved by the installer. Review the wizard's Extensions and Add-ons pages after updating, then restart StreamBridge and run the built-in readiness checks before the next live broadcast.
