# THSV StreamBridge 4.1.144

## Fixed

- If you ended the stream and went live again on the same scene (for example Starting Soon), Random Clip Player didn't start, and nothing else that waits for "stream started" or "stream stopped" heard it either. StreamBridge mistook the second start for a repeat of the first, because both looked the same, and dropped it. Each start and stop now counts as its own.

## How to update

Open the Wizard, press Check for updates and then Update now. Your settings and extensions are kept, and it never installs while you are live.
