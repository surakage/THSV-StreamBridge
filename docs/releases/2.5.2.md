# THSV StreamBridge 2.5.2

This release adds four independently installable community add-ons, expands the shared points foundation, and hardens wizard, overlay, scheduling, and package lifecycle behavior across the complete synchronized release.

## Highlights

- **Stream Labels** combines equivalent follows/subscribers, memberships, gift memberships, support, raids, rewards, and latest activity from supported platforms into persistent OBS-compatible labels.
- **Village Roll Call** provides one Twitch Channel Points daily check-in with a bounded monthly leaderboard and simulation-safe preview.
- **Prize Wheel** provides 2–10 equal choices, server-authoritative selection, a bounded animation, and platform-limited result messages.
- **Village Draw** provides free or Viewer Foundation points giveaways with bounded tickets, secure selection, persisted cancellation, and idempotent refunds.
- **Viewer Foundation** now supports a creator-named currency, `!points`, consistency bonuses, observation-based active/lurk awards, supported-event awards, and shared add-on spending/refunds.
- Viewer Foundation now rejects consistency farming inside the chat cooldown, preserves the first lurk start across repeated commands, and safely normalizes impossible activity-window settings.
- Creator Utility Pack now owns only counters and polls. Three Command Sync templates create its counter, poll-control, and vote commands.
- The wizard now gives exact no-duplicate-trigger setup for all new add-ons and preserves clear import/action boundaries.
- New beginner Bridge Core and all-add-on guides explain installation, triggers, action grants, overlays, tests, and loop avoidance step by step.
- All 32 first-party add-ons and all generated Streamer.bot imports are aligned to `2.5.2`.

## Install or update

1. Download `THSV-StreamBridge-2.5.2.zip` and `THSV-StreamBridge-2.5.2.zip.sha256` from this release.
2. Verify the checksum using `RELEASE-VERIFICATION.md`.
3. Extract the archive and run `Install THSV StreamBridge.cmd`.
4. Open the local wizard and follow [Beginner setup: Bridge Core](https://github.com/surakage/THSV-StreamBridge/blob/main/docs/setup-for-beginners.md).
5. Download an optional add-on from this same release, then follow its included `SETUP.md`. Import a matching `.sb` only when its guide says one is required.

Existing creator configuration, secrets, add-on state, uploads, logs, and backups remain outside the versioned application directory and are preserved by the installer.

## Acceptance boundary

Automated, offline/manual, and genuine-provider acceptance remain separate. Financial, moderation, reward, raid, Discord, translation, voice, and other side-effecting paths still require the provider evidence recorded in the wizard acceptance ledger.
