# THSV StreamBridge 4.1.110

## New

- Add all, Make starter scenes, Remove starter scenes and Save power on the Overlays page now work in SprigCast too. They make SprigCast blooms with Web page sources, placed the same way as in OBS, and never change a source or bloom you already have. The buttons and messages talk about blooms when SprigCast is your app.
- Snap and Discord screenshots can picture one source (such as your camera) or one bloom in SprigCast, not just the screen on air. Snap is now marked as working fully in SprigCast. An older SprigCast that can only picture the whole screen gets a clear "update SprigCast" message instead of a wrong picture.

## Changed

- The scene and source pickers for Snap and Discord screenshots list SprigCast's blooms and sources when OBS isn't connected.
- The SprigCast effects check says "Add the plugin" for a store plugin that isn't added yet, now that SprigCast lists every store plugin.
- The launcher starts SprigCast.exe when SprigCast has it (newer versions), so it shows as SprigCast in Task Manager. Picking pythonw.exe still works.
- Streamer Punishments, Prize Wheel and Stream Labels descriptions no longer say OBS only.

## Also in this update

- All new text is translated into the nine Wizard languages.

## How to update

Open the Wizard, press Check for updates and then Update now. Your settings and extensions are kept, and it never installs while you are live.
