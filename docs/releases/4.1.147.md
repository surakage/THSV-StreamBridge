# THSV StreamBridge 4.1.147

## Changed

- SprigCast now closes web pages that have been off screen for a few minutes, unless their **Keep running when hidden** is on. Some StreamBridge pages must not be closed: Alerts (the alert queue and sounds live in the page), Chat (the history lives in the page), Clips and Raid Scout (they report clip playback back to StreamBridge), Soundboard, Random Sound and the combined Sounds page (sound only), and Stream Break Countdown and Starting Soon Countdown (their sound cue). Each time StreamBridge connects to SprigCast it now switches Keep running when hidden **on** for those pages. It never switches it off and never touches any other page, so your own choices stay as they are. Every other StreamBridge page can close safely, because StreamBridge sends it its current state again when SprigCast reopens it.

## How to update

Open the Wizard, press Check for updates and then Update now. Your settings and extensions are kept, and it never installs while you are live.
