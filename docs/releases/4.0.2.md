# THSV StreamBridge 4.0.2

Version 4.0.2 strengthens startup recovery and makes pre-stream evidence easier to review, repeat, and compare without exposing creator secrets.

## Added

- The Wizard can discover connected StreamBridge browser sources by exact OBS program scene and save them as one-click expectations.
- Missing saved OBS expectations can be reconciled with a detected renamed scene through an explicit creator-approved update. StreamBridge never changes OBS itself.
- Live-acceptance checks explain the exact build, trigger catalogue, configuration, add-on version, or add-on-settings change that requires another test.
- Accepted startup, overlay, reconnect, and persistence checks receive a 90-day recheck date. Provider-event and feature-specific checks receive a 180-day date.
- Sanitized pre-stream reports combine build provenance, readiness, OBS inventory, live-acceptance status, and the latest startup run ID.
- An earlier pre-stream report can be compared locally with the current installed state. The Wizard classifies tracked regressions and improvements without storing the selected report.
- Optional browser-local history retains at most five sanitized reports for one-click comparison. It is off by default and can be cleared from the Wizard.
- Live-acceptance checks warn 14 days before their periodic due date and bind provider-specific checks to explicit adapter contract versions.

## Reliability

- Support-bundle previews now hold one tab-bound, one-use byte snapshot for five minutes. The downloaded archive must match the reviewed size and SHA-256 exactly.
- The Windows startup-chaos harness covers bounded retry, foreign port ownership, crash-loop protection, and transactional installer rollback.
- Tagged release packaging is blocked until startup chaos passes and the actual built ZIP completes clean-install, same-version repair, and previous-release upgrade checks while preserving creator data.
- Installed builds record a release-manifest digest and build fingerprint so support evidence distinguishes different builds with the same version.

## Install

Run `Install THSV StreamBridge.cmd` from the extracted release. The installer verifies every packaged file, preserves creator-owned data, performs a health-checked activation, and rolls back if activation fails.

After the Wizard opens, use **Streamer.bot → One Streamer.bot import** to generate the current combined import and trigger checklist for the features you use.
