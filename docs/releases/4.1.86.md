# THSV StreamBridge 4.1.86

## New

- In other languages, messages that include a changing value are now translated in all eight languages. That covers counts ("3 viewers updated"), names ("Settings saved for Chat Guard"), times ("5 min ago"), confirmation questions and most error messages, about 340 texts per language.

## Changed

- Very short translated patterns such as "Add …" only apply to a short name or number, so they can no longer change the start of an English sentence that has no translation yet.

## Fixed

- Translated texts with an optional ending (for example "Download & prepare" with or without a file size) now match in both forms.

## How to update

Open the Wizard, press Check for updates and then Update now. Your settings and extensions are kept, and it never installs while you are live.
