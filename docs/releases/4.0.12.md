# THSV StreamBridge 4.0.12

## Downloads

- [Download StreamBridge for Windows](https://github.com/surakage/THSV-StreamBridge/releases/download/v4.0.12/THSV-StreamBridge-4.0.12.zip)
- [Browse optional add-on downloads](https://www.slothbloom.com/projects/thsv-streambridge/downloads)

Extract the Windows ZIP and run `Install THSV StreamBridge.cmd`. Existing creator settings and credentials are preserved. Optional add-ons are not required for the built-in extensions.

## What's improved

- Corrected 7TV emote image URLs and avoided unsupported YouTube channel requests.
- Retained cached emotes during provider outages, with controlled retries.
- Updated compatibility support for newer Streamer.bot alpha releases.
- Aligned all 43 generated Streamer.bot import packages and first-party add-ons to 4.0.12.
- Consolidated maintenance notes and excluded private creator output from source and lint checks.

GitHub also stores technical verification files for automatic integrity and provenance checks. They do not need to be downloaded manually.
