# THSV StreamBridge 4.1.115

## Changed

- When a streaming app doesn't answer, Scene connections says which app and where to turn its connection on (OBS: Tools › WebSocket Server Settings; Streamlabs Desktop: Settings › Remote Control; Meld Studio: open the app; SprigCast: Settings › Connections), instead of "connect ECONNREFUSED".

## Fixed

- A saved SprigCast connection keeps working when SprigCast moves between 4455 and 4456 (for example when OBS is opened or closed), even if StreamBridge can't read SprigCast's connection file.
- The Discord screenshot page and its messages now say that SprigCast can take the picture too, saved in the first folder like OBS.
- Anything the Wizard hides now really stays hidden, so a row meant for one app can't show for another.

## Also in this update

- Translated: the SprigCast, Meld Studio and Streamlabs Desktop setup notes, the new connection messages, and about 25 more labels that were still in English, in all nine Wizard languages.

## How to update

Open the Wizard, press Check for updates and then Update now. Your settings and extensions are kept, and it never installs while you are live.
