# THSV StreamBridge 4.1.97

## New

- A Save power in OBS button on the Overlays page. It turns on OBS's "Shutdown source when not visible" for the StreamBridge overlays that only show a standing picture (Local Clock, Chat First, First Five, Fan Crown, Roll Call, Viewer Spotlight). Alerts, chat, captions, the Emote Wall, countdowns, timers, clips and games keep running. It refuses while you are live.

## Changed

- The overlay checklist ticks itself. Any overlay that OBS has loaded in the last 30 days counts as added, so Test & finish no longer shows "0 of 39 sources checked" when your sources are already in place. You can still tick the rest by hand.

## How to update

Open the Wizard, press Check for updates and then Update now. Your settings and extensions are kept, and it never installs while you are live.
