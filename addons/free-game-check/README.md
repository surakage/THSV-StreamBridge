# Free Game Check

Discovers newly listed PC and console giveaways from the public GamerPower feed and sends bounded, attributed announcements through StreamBridge's existing chat output. It is disabled by default, requires no API key, performs at most one scheduled lookup per configured interval, and stores only bounded giveaway IDs plus refresh status.

Import the bundled Streamer.bot package, leave **Refresh** triggerless, approve that action in the wizard, select chat destinations, and enable the add-on. This is discovery assistance, not a guarantee that a promotion remains available in every region.
