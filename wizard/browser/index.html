    Browser source and dock URLs

    Use the source URL for the on-stream layer. Use the dock URL in OBS Custom Browser Docks or any streaming host that accepts a local browser/web panel. If a host does not support custom docks, keep using its Browser Source with the source URL.

    For the crispest OBS chat, use the responsive URL as a Browser Source and start at 680 × 800. Set Width and Height to the final on-canvas pixel size, then move it without scaling the transform. Use the full-canvas source only when you plan to crop it without enlarging or shrinking it.

    Alerts

    Configure how normalized alerts appear in Meld, OBS, Streamlabs, or any compatible browser source. Pick a platform, then an event, to edit it — each is independent.

    Preview is always simulated. It never charges, subscribes, raids, or posts to chat. Ko-fi and Streamlabs donation previews are available.

    Speaker.bot is opt-in. Visual thank-yous are configured here. Spoken thank-yous, viewer-message speech, thresholds, filtering, and queue controls are configured under Add-ons > Voice Relay, so a disconnected voice service can never block the browser alert.

    Donation provider setup
    Connect the provider in Streamer.bot before enabling its StreamBridge intake. StreamBridge does not log in to payment providers or store their API tokens.

    Ko-fi — supported

    Create the verified Ko-fi webhook through the Streamer.bot website, import the Ko-fi Donations .sb package, and attach Integrations > Ko-Fi > Donation to its intake action. Then install and enable the Ko-fi add-on here.

    Template tokens — what each one means
    {actor}
    Who triggered the alert. Falls back to "The community" when no user is attached (like-milestone alerts).
    {alertType}
    The alert's own category, e.g. "gift subscription" — useful when one template covers several alert types.
    {platform}
    Which platform the event came from: twitch, youtube, kick, or tiktok.
    {amount}
    The monetary amount. Only set for cheers with bits, and Super Chat / Super Sticker.
    {currency}
    The ISO currency code that goes with {amount}.
    {quantity}
    A count — gifted subscriptions, cheer bits, or gifted months — depending on the alert type.
    {itemName}
    The name of the gifted item, when the platform provides one (e.g. a TikTok gift's name).
    {tier}
    The subscription tier, when the platform reports one.
    {message}
    Any accompanying text — a cheer message, a resub message, and so on.
    {metric}
    Which metric a like-milestone alert is about (currently only "likes").
    {value}
    The metric's numeric value for a like-milestone alert.

    Quantity aggregation is available only for gifts and gift subscriptions.
