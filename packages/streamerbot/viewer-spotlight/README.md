# THSV StreamBridge — Viewer Spotlight

Import the `.sb` and keep **Settle Reward** triggerless. Approve it only when Twitch reward requests are enabled.

Rejected, expired, or undisplayable reward requests are refunded when that option is enabled. Other reward IDs are ignored.

Discord snapshots are posted by StreamBridge using the webhook you choose from **Platforms > Discord webhooks**. If you imported an older version, the **Discord Snapshot** action is no longer used and can be deleted.
