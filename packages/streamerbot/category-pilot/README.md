# THSV StreamBridge - Category Pilot

Import and compile all three actions. Approve Process Probe plus the needed Creator Controls Apply Profile actions for Category Pilot in the wizard. Process Probe must remain triggerless. Attach Apply/Dismiss only to creator-controlled hotkeys or deck buttons.

The probe receives a maximum of twenty exact process names and returns at most five matches. It never returns executable paths, command lines, window titles, process IDs, or a complete process inventory.
