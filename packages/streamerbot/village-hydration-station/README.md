# Village Hydration Station Streamer.bot package

Import `THSV-StreamBridge-Village-Hydration-Station-4.0.4.sb` into Streamer.bot 1.0.7 or newer.

- Attach **Log Water** to Stream Deck or a creator hotkey. A blank `hydrationAmount` uses the wizard's default serving.
- Hydration does not require Streamer.bot Voice Control. Use the broadcaster-only `!water` command or attach **Log Water** to a Stream Deck button or creator hotkey.
- Attach **Undo**, **Snooze**, and **Reset** only to creator controls.
- Keep **Preview Reminder** triggerless and run it manually when sizing the overlay.
- Keep **Speak** triggerless. Approve it only when optional Speaker.bot confirmations are enabled.

Twitch and Kick reward redemptions continue through the existing main THSV platform intake actions. YouTube and TikTok `!hydrate` commands register through StreamBridge and do not need duplicate Streamer.bot Command objects.
