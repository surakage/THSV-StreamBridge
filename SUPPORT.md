# Getting help

## First, check these

- [Quick start](docs/guide/quick-start.md): the whole first setup on one page.
- [Troubleshooting](docs/troubleshooting.md): fixes for the most common problems.
- The wizard's **Setup checklist** (right under **Overview**): it lists exactly what each feature still needs.
- The wizard's **Diagnostics > Run pre-stream check**.

## Asking for help

Open an issue with the **Bug report** template. Include:

- your StreamBridge version (shown in the wizard under **Bridge updates**);
- which platforms and streaming app you use;
- what you expected and what happened instead; and
- the **support bundle** from **Diagnostics > Preview support bundle**. It removes tokens and keys for you.

Never post your recovery key, control token, stream keys, webhook links or platform tokens, in an issue or anywhere else. Nobody helping you needs them.

## Ideas and add-ons

Use the **Feature request** template for ideas. To build your own add-on, start with [Add-on development](docs/add-on-development.md).
